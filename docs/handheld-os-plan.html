Handheld OS plan

18 devices, 10 of them on Android (ES-DE). The other 8 run Knulli, Onion and NextUI today. Spruce's wiki and sync-roms main (release 3.19.0) both list every one of them as supported, so a single non-Android OS is possible. This page lays out what each device can run, how offline RetroAchievements and a game switcher compare, and the plans that follow.

One OS is possible

Spruce runs on all four Miyoos and, per its wiki, on the RG35XX H, RG40XX V, RG CubeXX and RG SP. It has the game switcher, offline RA and a Syncthing app, and sync-roms main already writes its collections (PR #427).

The catch on Anbernics

Spruce's wiki says the Anbernic H700 devices need a BaseOS image on card slot 1, with Spruce on slot 2. Check what that means for your RG SP's 32 GB card and for each device's current card.

Still unverified

What lid-close sleep does on Spruce clamshells (only wake-on-open is documented), and whether Spruce's Syncthing works well on the H700s. sync-roms' Spruce layout notes still describe Miyoo devices only, so check that it writes the right folders on an H700 card.

Fallbacks

If Spruce on the H700s disappoints, ROCKNIX or muOS cover all four H700s for a two-OS result, and sync-roms main has a layout with collections for each. Neither has a game switcher that I found.

Plans by preference

Each plan lists where every non-Android device ends up. Android devices don't change in any of them.

One OS: Spruce on every Miyoo and Anbernic handheld

1 non-Android OS

Pick this if you want the fewest systems to configure and the Onion-style game switcher on every non-Android device.

SpruceMiyoo Flip, Mini, Mini Flip, Mini Plus, RG35XXH, RG40XXV, RGCUBEXX, RGSP

You gain: a switcher on all 8 devices, offline RA without installing a proxy, Syncthing and file-transfer services on the WiFi devices, wake-on-open on Anbernic clamshells, and collections (sync-roms main already writes them). You give up Knulli, Onion and NextUI. Costs and risks: the H700 devices need a BaseOS image in slot 1 and Spruce in slot 2; lid-close sleep and Syncthing behavior on the H700s are unverified; Spruce's offline cache covers RetroArch games only; the wiki and the release page disagree about a few non-Anbernic devices, so check both before flashing; sync-roms' Spruce layout notes only mention Miyoo devices, so try it on one H700 card first.

Spruce on the Miyoos, a second OS on the H700s

2 non-Android OSes

Pick this if the BaseOS requirement is a problem, or Spruce on an H700 disappoints after a trial on one device.

SpruceMiyoo Flip, Mini, Mini Flip, Mini Plus
ROCKNIX or muOSRG35XXH, RG40XXV, RGCUBEXX, RGSP

ROCKNIX: built-in Syncthing, offline RA through the proxy, a sync-roms layout with collections (installed once by running a Ports script). muOS: offline RA through the proxy, sync-roms collections already work, mixed lid-sleep reports. Neither has a game switcher that I found.

Closest to what you run today

3 non-Android OSes

Pick this to change as little as possible while fixing the RG SP.

KnulliMiyoo Flip, RG35XXH, RG40XXV, RGCUBEXX
Onion3 Miyoo Minis, unchanged
muOS, ROCKNIX or SpruceRGSP, replacing NextUI

Gain: the proxy path the repo already documents on four devices, offline RA on the RG SP. Still true: the Flip has no switcher, and you keep three systems to configure.

Whichever plan you pick, sync-roms main already lists the right firmwares for all eight devices, including no Knulli on the RG SP.

What this page rests on:

  • The repo, on main at release 3.19.0: device firmware lists, WiFi flags, the Knulli and Android RAOfflineProxy steps in the setup guide, the Spruce, ROCKNIX and NextUI layouts (collections, EZ Updater staging, ROCKNIX proxy install), and the revert (#447) that stopped sync-roms installing the proxy on Spruce cards.
  • Spruce: README, wiki Supported Devices, v4.6.0 release, v4.5.0 coverage, v4.4.0 release, v4.3 coverage. The wiki's "Latest Release" is given for every device, so there is no per-device Spruce version.
  • ROCKNIX: device list, Cloud Sync (Syncthing), Fake Suspend, RetroAchievements, RAOfflineProxy v1.6.0-alpha1. The RG SP isn't on that device index; it is on ROCKNIX's releases page, which you confirmed and I haven't read myself.
  • Others: RAOfflineProxy on muOS, RAOfflineProxy v1.0.1-alpha4 (Onion), NextUI H700 rc5.
  • Not checked: whether the Spruce layout's folders and saves are right on the H700s, Spruce lid-close sleep, Spruce Syncthing on the H700s, how much of the slot 1 BaseOS setup you already have, game switchers on Knulli, muOS, NextUI and ROCKNIX, and Syncthing on Onion.
