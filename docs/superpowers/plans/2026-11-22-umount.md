# `sync-roms umount` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `sync-roms umount` picks a mounted external card, runs sync's card tidy on its volumes and unmounts it.

**Architecture:** New `umount.py` reusing `flash.external_disks`/`flash._disk_label` for the picker and `clean.clean_dirs`/`clean.eject` for the tidy and unmount. Wired as a `commands.COMMANDS` command.

**Tech Stack:** Python 3.12+, `unittest`, `diskutil` (macOS).

**Spec:** `docs/superpowers/specs/2026-11-22-umount-design.md`

## Global Constraints

- Run everything with `uv run` (tests: `uv run python -m unittest discover -s tests`). Code must run on Python 3.12.
- Test modules import `isolate` first (directly or via `helpers`) before `sync_roms`.
- macOS only: on another platform print `❌ umount needs macOS` with `ui.failure` and return 1.
- No arguments beyond the `common(p, card=False)` flags; never reads or writes storage.
- Conventional Commits, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- A card whose volumes are not mounted (only unmounted partitions): not offered, since there is nothing to unmount → tested in Task 1 (`test_parse_disks_reads_mount_points` + `test_run_lists_only_mounted`).
- Unmount fails (card busy): exit 1, the existing busy hint is printed → `test_run_returns_1_when_unmount_fails`.
- Esc in the picker: nothing cleaned or unmounted, exit 0 → `test_run_esc_does_nothing`.
- Storage `root` on an external disk: that disk is never offered → `test_run_excludes_storage_disk`.
- Card with two mounted volumes (e.g. KNULLI + SHARE): each gets the tidy before the one unmount → `test_run_cleans_each_mount_then_unmounts`.
