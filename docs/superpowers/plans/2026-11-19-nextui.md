# NextUI Layout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `nextui` as a card layout with folders, BIOS, saves, art, collections, Surprise, multi-disc, device data, guide and docs, so the RG SP and RG34XX SP can run NextUI.

**Architecture:** NextUI is a data layout (`layouts.json`, `systems.json`, `devices.json`) plus small per-feature branches next to the existing Onion/Knulli ones. A system's folder is `"<Name> (TAG)"`; the tag, derived from the folder, drives BIOS (`Bios/<TAG>/`) and saves (`Saves/<TAG>/`).

**Tech Stack:** Python, `unittest` (`python -m unittest discover -s tests`), JSON data in `src/sync_roms/data/`.

**Spec:** `docs/superpowers/specs/2026-11-19-nextui-design.md`

## Global Constraints

- Existing layouts behave exactly as before; their tests stay green.
- Conventional Commits, imperative, lowercase (`feat(nextui): ...`).
- No NextUI code or assets copied into the repo; no notes about bucket contents in repo files.
- Per CLAUDE.md the setup guide gets only steps the user gave: the NextUI layout name and platform, no invented install or settings sections (this narrows the spec's "sections" line; say so in the final report).
- Saves use NextUI's default MinUI naming (`Game.gba.sav` = ROM file name + `.sav`).
- `anbernic-rg-sp` and `anbernic-rg34xx-sp` firmwares become `["nextui", "knulli"]`; other devices unchanged.
- Skip tiny Ctrl-C edge cases (only hangs, crashes, data loss, broken terminal count).

## Review Focus

- A card whose games name a system with `nextui: null` skips it with the existing "no folder" message instead of crashing (Task 2 test).
- `.media/` art folders are never treated as extras or deleted by cleanup (Task 5).
- A collection whose games are all on null-folder or not-on-card systems writes no file and leaves none behind (Task 6).
- A `.srm` with no matching ROM on the card is left unconverted and reported, never renamed blindly; PlayStation saves are never renamed (Task 4).
- `--dryrun` on a NextUI card writes nothing, including `Collections/` (Task 6).
