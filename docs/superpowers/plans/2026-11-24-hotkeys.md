# One Hotkey Scheme Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** spruceOS's default RetroArch hotkeys everywhere with quit on hotkey + Start: set on spruce cards by sync and `config apply`, on Android by `config apply`, and described simply in the setup guide.

**Architecture:** A repo data file `hotkeys.json` holds the scheme and Android's keycodes. A new `spruce_hotkeys.py` changes only the quit line in a spruce card's `Saves/ra-configs/retroarch-*.cfg`, using the Start value from spruce's own platform script on the card. `android_settings.cfg_wanted` adds the full scheme. The guide's Hotkeys section is rewritten from the scheme.

**Tech Stack:** Python 3.12+ (stdlib), unittest, `uv run`; one self-contained HTML page.

**Spec:** `docs/superpowers/specs/2026-11-24-hotkeys-design.md`

## Global Constraints

- Always `uv run`; tests: `uv run python -m unittest discover -s tests` (stdin closed: `< /dev/null`).
- Test modules import `isolate` first (directly or via `helpers`).
- Code runs on Python 3.12.
- Card text files are written with `cardfs.write_text`; read raw bytes with `cardfs.read` to keep CRLF.
- Conventional Commits, lowercase imperative, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Never touch storage; no real game lists in the repo.
- Scheme (hotkey + …): menu X, save R1, load L1, slot −/+ D-pad Left/Right, fast-forward toggle R2, slow motion toggle L2, FPS Y, quit Start.
- Android keycodes: Select 109, Start 108, X 99, Y 100, L1 102, R1 103, L2 104, R2 105, D-pad Left `h0left`, Right `h0right`.

## Review Focus

- A card whose cfg has CRLF line ends: the quit line is replaced and every other line keeps CRLF (Task 2 test).
- A platform whose `RA_START_VAL` is only in a family file it sources (Anbernic XX → `AnbernicXXCommon.cfg`): the value is found through the `. /mnt/SDCARD/...` line (Task 2 test).
- The A30 (keyboard names: `RA_HOTKEY_LINE="input_enable_hotkey"`, `RA_START_VAL="enter"`): writes `input_exit_emulator = "enter"`, not the `_btn` line (Task 2 test).
- A card whose hotkey button is Start (its hotkey-enable line already equals `RA_START_VAL`): skipped with a warning, file unchanged (Task 2 test).
- An Android `retroarch.cfg` with a vendor preset (the RG Cube's slots on 104/105 and fast-forward on 96): after apply, no hotkey key other than the scheme's holds a scheme button (Task 3 test).

**Interfaces:**
- Consumes: nothing from Task 1 at runtime (spruce changes only quit; the button is spruce's).
- Produces:
  - `start_value(base: str, platform: str) -> tuple[str, str] | None`: `(quit key, Start value)` for the platform, e.g. `("input_exit_emulator_btn", "6")`, `("input_exit_emulator", "enter")`; None when not found.
  - `entries(base: str) -> list[applied.Entry]`: one per `Saves/ra-configs/retroarch-<P>.cfg`, `where` `Saves/ra-configs/retroarch-<P>.cfg`, `key` the quit key, `old` its current value (None when missing), `new` the Start value, `secret` False. Warnings via `ui.warn`, as in `install`.
  - `install(card: str, layout_name: str, base: str, dry_run: bool) -> int`: failure count; 0 and no output for layouts other than `spruce`.

Behaviour:
- Platform script: `spruce/scripts/platform/*/<P>.cfg` on the card (glob with `glob.escape(base)`). Read `RA_HOTKEY_LINE` and `RA_START_VAL` from `NAME="value"` lines; a line `. /mnt/SDCARD/<path>` loads `<base>/<path>` at that point (recursively, each file once). Last assignment wins.
- Quit key: `RA_HOTKEY_LINE.replace("enable_hotkey", "exit_emulator")`.
- Edit with `spruce_syncthing._pattern(key)` the same way `spruce_syncthing.retroarch_writes` does (keep the file's line ends; append when missing; unchanged when it already holds the value, quoted or not).
- Skip one cfg with a warning, other cfgs still done:
  - no platform script or no values: `Saves/ra-configs/retroarch-<P>.cfg: spruce's Start button for <P> wasn't found; quit left on its default`
  - hotkey is Start (the cfg's `RA_HOTKEY_LINE` value equals the Start value): `Saves/ra-configs/retroarch-<P>.cfg: the hotkey button is Start, so quit stays on spruce's default`
  - unreadable cfg: `… can't be read; its quit hotkey left as it is`
- No `Saves/ra-configs/retroarch-*.cfg`: one warning `Saves/ra-configs has no retroarch-*.cfg yet; launch a game once on the device, then sync again for the quit hotkey`.
- Output when written (not dry run): `🎮 Quit hotkey set to hotkey + Start in <n> RetroArch config(s)`; dry run: the same with `Would set`. A write error: `ui.warn(f"... can't be written: {e}")` and count 1.
