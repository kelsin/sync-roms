`fusion-pixel-12px-proportional-ja.ttf`: [Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font) by TakWolf,
release 2026.11.10, 12px proportional, Japanese variant (Latin, kana, CJK and Hangul), licensed under the
[SIL Open Font License 1.1](OFL.txt). `LICENSES/` holds the licenses of the fonts it is built from (Ark Pixel,
Cubic 11, Galmuri).

It is the font of the custom Pixel themes (`custom_themes/pixel/build.py`) and the palette previews. It is a 12px
pixel font, so it is only crisp at sizes that are multiples of 12.
